    Provider fi_syke
    Country Finland

    Read from Syke's Hydrologiarajapinta OData hydrology interface (rajapinnat.ymparisto.fi)
    Quantities Daily discharge, stage and surface water temperature
    Stations in the catalogue 2,543. Availability depends on quantity

    Agency documentation Syke open data and web services

    RivRetrieve reads Syke's Hydrologiarajapinta OData service. Retrieve one week of published daily discharge at station 894, Ruskeakoski on the Jänisjoki:

    import rivretrieve as rr

selection = rr.find(
    provider="fi_syke",
    station="894",
    quantity="discharge",
)

result = rr.fetch(selection, start="2020-01-01", end="2020-01-07", cache="bypass")

preview = result.data.select("time", "time_zone", "value", "unit").head(3)
print(preview.write_csv(), end="")

print(result.data.height)
print(result.issues)

    Output:

    time,time_zone,value,unit
2020-01-01T00:00:00.000000,unknown,16.73,m3/s
2020-01-02T00:00:00.000000,unknown,17.79,m3/s
2020-01-03T00:00:00.000000,unknown,19.02,m3/s
7
()

    The request returned seven daily values in m³/s, one for each date from January 1 to 7. The preview shows the first three. The empty tuple () means retrieval reported no issues; it does not establish the quality of the values. time_zone is unknown because Syke's timestamps carry no UTC offset. All three fi_syke series have frequency="daily", and the request did not restrict by statistic because Syke's service does not state whether a daily value is a mean, an instantaneous reading, or another statistic.

    cache="bypass" requests Syke's service rather than a local cache. This output was checked live on 2026-11-08. Published values can change, so a later retrieval need not reproduce this output exactly. See Usage for general selection and result handling.

    Who measures, and who publishes

    Syke operates Finland's national hydrology API and publishes station and observation data through it. Some of the stations in the catalogue are measured by Syke directly; others are measured by regional ELY-centres (Centres for Economic Development, Transport and the Environment) or other bodies that report into Syke's systems. The API does not publish an operator field per station, so RivRetrieve cannot state who measures a particular station; it publishes what Syke publishes.

    Station identifiers are Syke's own per-installation site identifier (Paikka_Id), confirmed against Syke's public map service and against the independently published CAMELS-FI dataset, both of which key on the same identifier. In Syke's station table (Paikka), each Paikka_Id is associated with one of the three admitted quantities: a river gauge with both discharge and stage readings appears as two separate Paikka_Id stations in the catalogue, one per quantity, rather than one station with two available products.

    What you can retrieve

    Quantity filter Source field / variant Frequency Statistic Source unit Returned unit
    discharge Virtaama Daily Unknown m³/s m³/s
    stage Vedenkorkeus Daily Unknown cm m
    temperature LampoPintavesi Daily Unknown °C °C

    The source field is the Hydrologiarajapinta OData entity-set name, where each row's numeric reading is published in Arvo. Each quantity has one daily series per station, so variant stays unset (variant=None). RivRetrieve converts stage from centimetres to metres; discharge and surface water temperature need no unit conversion. All three series have frequency="daily", whereas statistic is unknown because Syke's documentation and metadata tables do not state whether a published daily value is a mean, an instantaneous reading, or another aggregation. Do not filter by statistic="mean" when selecting fi_syke series.

    Stage is an absolute water-surface elevation relative to a Finnish national height datum, not a small reading relative to a local gauge zero: published stage values range from about -2 m to +245 m, consistent with Finland's coast-to-inland relief (vertical_reference="above_sea_level"). Which of Finland's historical national height systems (such as N2000, N60, NN, or N43) a given reading is expressed in is not stated on observation rows, so vertical_datum remains None and RivRetrieve does not apply Syke's separate per-station datum-offset table (VedenkTasoTieto).

    Depth-profile water temperature soundings (LampoLuotaus, which vary by measurement depth) and catchment runoff series (Valuma) are not included in fi_syke.

    In Syke's Paikka table, 711 stations are witnessed for discharge, 1,753 for stage, and 79 for temperature. The packaged catalogue records availability="available" for a station's witnessed quantity and availability="unknown" (rather than "unavailable") for the other two quantities. Because RivRetrieve keeps pairs with "unknown" availability selectable, pass quantity when selecting a station so the selection targets only that quantity, and note that a provider-wide query such as rr.find(provider="fi_syke", quantity="discharge") includes both the 711 stations witnessed for discharge and the remaining stations whose discharge availability is "unknown". A station being listed does not guarantee data for every requested period.

    How far back, and how recent

    Coverage varies by station. The example station, 894, has published discharge back to January 1, 1959. Some stations hold decades of history; others have shorter or more recent records. RivRetrieve reads whatever range Syke currently publishes for a station; there is no fixed earliest or latest date imposed by RivRetrieve. Checked live on 2026-11-08, several active stations had daily values published within the preceding one to two days.

    A request for a period with no published observation returns no rows for that period rather than an issue. It does not establish that the station never had data in that period.

    Time and data status

    Syke's timestamps carry no time zone marker, and the agency's documentation does not state one. RivRetrieve returns the published wall-clock label in time paired with time_zone="unknown". Do not assume these timestamps are UTC, Finnish local time, or any other specific zone.

    Some discharge and stage readings carry Syke's integer flag key Lippu_id, which points into Syke's Lippu reference table covering mixed meanings: data-quality notes (for example, interpolated or reduced values), statistical summaries, model-simulated values, and device identifiers. RivRetrieve exposes Lippu_id verbatim on discharge and stage results in the fi_syke.observations annotation schema without dropping flagged rows or ranking one code above another. Pass annotations=True to result.to_polars(...) or result.to_pandas(...) to project Lippu_id, or call rr.annotations(result) to inspect schema metadata. Surface water temperature (water_temperature_reported) carries no Lippu_id field and emits no observation annotations. See Source annotations for general options.

    Some older discharge and stage readings also carry a published minimum and maximum alongside the daily value; current readings do not. RivRetrieve does not return these minimum and maximum fields, since Syke does not state what they represent.

    A published null remains a row with value=null. A date without a published observation supplies no row. A failed request remains an issue alongside any successful records. Check issues before interpreting an empty result.

    Terms and citation

    Syke's open-data terms state:

    Open data distributed by the Finnish Environment Institute (Syke) is licenced under Creative Commons Attribution 4.0 International licence. The data covered by the license can be freely used in any way, provided that the source of the data is mentioned: the name of the licensor and the name of the data.

    Syke's worked example of attribution reads "Source: Finnish Environment Institute (Syke)". Retrieval requires no personal credentials.
